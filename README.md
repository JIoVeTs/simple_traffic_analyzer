# Traffic Analyzer

Консольное приложение на C++ для анализа сетевого трафика в формате libpcap.

## Что умеет программа

- открывает файл .pcap;
- читает заголовок файла и выполняет подсчёт пакетов;
- вычисляет минимальную, максимальную и среднюю длину пакета;
- определяет типы протоколов: Ethernet, IPv4, TCP, UDP;
- считает количество пакетов IPv4, TCP и UDP;
- выводит содержимое пакета в 16-ричном виде;
- отображает декодированную служебную информацию заголовков протоколов;
- позволяет выбрать номер пакета и вывести его разбор на экран;
- поддерживает работу в Windows Visual Studio.

## Сборка и запуск

1. Откройте файл `Traffic_Analyzer.slnx` в Visual Studio.
2. Выберите конфигурацию `Debug` или `Release` и платформу `x64`.
3. Нажмите `F5` или соберите проект.
4. В консоли введите путь к .pcap файлу, например:

   `C:\Users\vladi\Desktop\Traffic.pcap`

5. После отображения статистики введите номер пакета для просмотра.
6. Введите `0`, чтобы завершить работу.

## Структура проекта

- `Traffic_Analyzer/` — исходный код проекта
  - `Traffic_Analyzer.cpp` — точка входа, интерфейс пользователя
  - `PacketSequence.*` — работа с последовательностью пакетов и статистикой
  - `Packet.*` — пакет и его вывод в hex и декодирование
  - `Ethernet.*` — Ethernet II
  - `IPv4.*` — IPv4
  - `TCP.*` — TCP
  - `UDP.*` — UDP
- `bin/` — скомпилированная версия приложения
- `README.md` — описание проекта
